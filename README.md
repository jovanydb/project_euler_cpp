# Project Euler – C++ Solutions

A collection of my solutions to the problems from [Project Euler](https://projecteuler.net/).  
Some solutions are still work-in-progress as this is an ongoing project for me.  
All solutions here are implemented in **C++17**.

## Purpose
- Practice algorithmic and mathematical problem-solving through Project Euler’s challenges.  
- Deepen understanding of C++ fundamentals such as templates, STL containers, recursion, and performance optimization.  
- Explore efficient approaches to number theory, combinatorics, and dynamic programming problems.  
- Build a portfolio of clean, readable, and well-structured C++ code that demonstrates logical reasoning and algorithmic efficiency.

## Repository Structure
Each problem is implemented in its own source file (e.g., `problem_1.cpp`, `problem_2.cpp`, etc.), with minimal boilerplate for clarity.  
Some problems may include helper functions or utility headers for reusable mathematical operations.
